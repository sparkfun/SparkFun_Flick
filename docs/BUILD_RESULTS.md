# Build results

Generated by `python tools/benchmark.py` on 2026-10-18.

- Machine: Intel64 Family 6 Model 170 Stepping 4, GenuineIntel, Windows 11, Python 3.13.15
- Sketch compiler: xtensa-esp32s3-elf-gcc 14.2.0
- Arduino-ESP32 core: 3.3.11
- Board: SparkFun ESP32-S3 Thing Plus

The **Baseline** firmware already on the board is **1,595,856 bytes**. It contains WiFi, HTTPS, BLE, ESP-NOW, I2C, ADC, PWM, the RGB LED driver, and the sketch loader. A sketch contains only your code and calls into Baseline through a table of function pointers.

## Compared with a normal Arduino build

The same programs written as ordinary Arduino sketches (`benchmarks/arduino/`), built with arduino-cli for `esp32:esp32:sparkfun_esp32s3_thing_plus:CDCOnBoot=cdc,PartitionScheme=huge_app`.

- **Arduino clean**: `--clean`, so nothing is cached. This is the first build, or the first after changing board options.
- **Arduino rebuild**: only the sketch changed. The core and libraries come from cache. This is the everyday edit-compile loop.
- **Upload size**: what has to be sent to the board. For Arduino this is the full application image (esptool compresses it on the wire). For Flick it is the `.flick` file.

## Notes

- Upload times are not measured by this script. Measured by hand on 2026-10-18 (see readme.md): `flick upload` takes about 0.03 s for the upload itself; `arduino-cli upload` takes 7-9 s.
- Example images are not stand-alone firmware: they only run on a board that has the matching Baseline (ABI 1.x) installed.
