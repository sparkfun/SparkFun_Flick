# Teensy Audio library objects in Baseline (ABI 1.8, i.MX RT1062 only).
#
# Run `python flick/tools/gen_audio.py` after editing. It regenerates:
#   sdk/include/baseline_audio.h                   sketch-side proxy classes (same names and
#                                                  methods as the Audio library, so code from
#                                                  the Audio System Design Tool compiles)
#   chips/imxrt1062/baseline/bl_audio_dispatch.inc Baseline's constructor and method switch
#
# The numbers are part of the ABI, like api/baseline_api.txt:
#   * never renumber or remove a class or a method, never change a signature;
#   * new classes get a new type number; new methods go at the end of their class.
#
# Format:
#   class <Name> | <type number> | stream|control | <constructor params or -> | <#if condition or ->
#   <method number> | <return type> | <name> | <params>
# Params use the Audio library's C++ types. "enum:T" is an int the Baseline casts
# to T; defaults ("float q = 0.7071f") are applied in the sketch.
# Every stream object also answers processorUsage(), processorUsageMax() and
# processorUsageMaxReset() (methods 1000-1002, handled by Baseline).
