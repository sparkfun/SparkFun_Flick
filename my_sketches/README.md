# Your sketches

Put your own sketches here. A sketch is a folder with a `.ino` file of the same name: `my_sketches/plant_monitor/plant_monitor.ino`.

`hello_flick/` is already here for you to change: open `hello_flick.ino`, edit the message, and press **Ctrl+Shift+B**.

- **Start one:** `python flick.py new plant_monitor` creates `my_sketches/plant_monitor/`. In VS Code, run the task **New sketch** (Terminal > Run Task).
- **Or copy an example:** copy a folder from `examples/` to here, then rename the folder and its `.ino` file to match.
- **Upload it:** open the `.ino` file and press **Ctrl+Shift+B**.
