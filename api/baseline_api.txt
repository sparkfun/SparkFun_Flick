# Baseline API - single source of truth.
#
# Run `python tools/gen_api.py` after editing. It regenerates:
#   sdk/include/baseline_api.h       (bl_api_t + sketch-side wrappers)
#   baseline/src/gen/bl_impl.h       (prototypes Baseline implements)
#   baseline/src/gen/api_table.c     (Baseline's table instance)
#   docs/API.md
# and checks api/abi.lock so the table stays append-only.
#
# RULES
#   * Append new entries at the END only, with minor = current minor + 1.
#   * Never reorder, remove, or change an existing line's return/name/params.
#     That needs abi_major + 1 (and every sketch must be rebuilt).
#   * Use plain C types / bl_* types from baseline_types.h. No IDF types.
#   * Callback parameters must use a typedef from baseline_types.h.
#
# Format:  minor | return type | field | params | sketch wrapper | description
#   field           -> member of bl_api_t, implemented in Baseline as bl_impl_<field>
#   sketch wrapper  -> name sketches call ("-" for none). Variadic entries become macros.
#                      "@name": the SDK writes name() by hand (sdk/include/baseline.h).
